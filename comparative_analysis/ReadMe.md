# Comparative Analysis 

The effectiveness and benefits of our library have been validated through comparative analyses. In two studies, we compared the image processing steps in workflows created using the base visual programming language for image processing (VPL4IP) and the one enhanced by our im2im library. We also assessed the technical demands on users for building such workflows. Both VPL4IPs are built on Blockly. In a third study, we compared the implementation workload when using numpy ndarray as the intermediate representation versus our automated approach.
