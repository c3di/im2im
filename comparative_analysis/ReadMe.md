# Comparative Analysis 

The effectiveness and benefits of our library have been validated through comparative analyses. 




In two studies, we compared the image processing steps in workflows created using the base visual programming language for image processing (VPL4IP) and the one enhanced by our im2im library. We also assessed the technical demands on users for building such workflows. Both VPL4IPs are built on Blockly. [![Open in Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/drive/1cf5M1gOMdMXaRIKsCYalVj99RzMYSy8C?usp=sharing) 

***\*NOTE\****  Blockly for both versions of VPL4IP, does not include an execution environment. Therefore, to demonstrate and validate the functionality of our im2im library, we manually copied the generated code from the VPL4IPs interface and executed the code in CoLab. This manual process was necessary to verify that our library operates as intended. 



 In a [third study](https://github.com/c3di/im2im/blob/main/comparative_analysis/3/Implementation_Comparison.pdf), we compared the implementation workload when using Pillow Image as the intermediate representation versus our automated approach.
